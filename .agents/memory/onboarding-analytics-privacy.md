---
name: Onboarding analytics privacy
description: Privacy boundary for Club Agent onboarding measurement.
---

Measure public onboarding using only event names and fixed UI locations/outcomes.
Never include Discord IDs, server IDs, player names, link codes, staff content or
free-text evidence in custom analytics.

**Why:** The user wants to understand onboarding without exposing private club records.

**How to apply:** Keep future custom event dimensions limited to predefined labels.
Do not attach response objects, link URLs or identity information to events.
